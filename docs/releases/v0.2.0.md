# APO v0.2.0 — Portable rules and reviewable upgrades

本版面向需要持续维护 AI 编程项目的创作者：去除通用规则中的个人 Fleet/box 和 Cursor Bugbot 强制依赖，保留项目治理、可验证证据和人类决策边界。

## 本版包含

- #67：外部项目初始化不再必须登记作者个人 Fleet/晨报；本方法论仓的 self-dogfood Fleet SoT 指针保留。
- #68：通用审查不再绑定 `bugbot run`；项目明确要求的 CI、审查、证据和 Accept 不变。
- #69：Worktree 任务基线可显式选择、读取项目配置或核实远端默认；歧义失败关闭，并提供候选给用户决定。
- #72：初始化拒绝未提交的方法论源，避免 PIN SHA 与快照不一致。
- #73：初始化默认仅 origin，高级远端显式启用；Command Center 模板使用真实来源/PIN。
- #77：只读本地 Doctor，检查 PIN 格式、远端分类及 Hook，未检查的服务端保护和控制面诚实报告 UNKNOWN。
- #88：新增 `upgrade-project` Skill 和只读 `scripts/prepare-upgrade.py`。从旧 PIN 与新版 Git 对象进行三方比较、保留项目规则、输出稳定预览和标准 Git 补丁。用户在隔离任务工作区通过 Git 校验和应用，原提交/原工作区和反向补丁提供回退路径。

## 安装

```bash
git clone --branch v0.2.0 https://github.com/Dylan5237/agent-project-ops.git apo-v0.2.0
cd apo-v0.2.0
```

新项目使用 `bootstrap-project` Skill 或 `bash scripts/bootstrap-project.sh`。旧项目使用 [中文升级指南](https://github.com/Dylan5237/agent-project-ops/blob/v0.2.0/docs/UPGRADE.zh-CN.md) / [English upgrade guide](https://github.com/Dylan5237/agent-project-ops/blob/v0.2.0/docs/UPGRADE.md)，不要在已有目录重新初始化或只修改 PIN。

升级需要 Git、Python 3.10+ 和包含旧 PIN 提交的可信完整方法论克隆；shell 流程需要 Bash（Windows 可用 Git Bash）。随附源码压缩包用于离线审阅，没有 Git 历史，不能直接用作升级来源。发行附件包含 `RELEASE_SHA.txt` 和 `SHA256SUMS`。

## 兼容性与限制

- 自动补丁路径支持已知旧版 bootstrap 绑定结构，并以真实 v0.1.2 初始化项目验证升级、保留自定义规则、回退和幂等。自定义快照、未知 PIN、不能重建的手写绑定、冲突或脏工作树会停止；不提供强制覆盖。
- 本地规则更新**不等于**项目 GitHub CC/Phase 已更新。升级 Skill 会要求按项目授权协调继承的旧通用要求，保留实际项目政策和历史证据；脚本本身不写任何远端项目。
- 不自动升级任何已有项目，不自动提交/合并业务 PR，不改变生产环境。
- #75 的通用自然语言三旅程入口未通过真实用户/跨宿主 UX 验证，**不纳入本版**。本版提供的是独立的升级 Skill、脚本和既有核心治理能力。
- CI 验证的是合同与隔离项目操作，不能证明任意 AI 宿主均遵守规则、独立人类身份可强制验证或业务产品已验收。
