# 可选接入：Grok Bot

本项目选择了 Grok Bot；这份说明只定义接入边界，不会自动安装机器人、添加检查或连接账号。

1. 先确认项目可用的机器人入口、维护人和调用权限；没有明确入口时保持未连接，不猜测命令或服务地址。
2. 如需辅助审查，通过项目任务写明审查对象的完整提交 SHA、只读范围和输出位置。机器人意见属于审查证据，由主 Agent 核对后处理。
3. 不把机器人设成通用必需门禁，不让它替拍板人批准或验收。项目另行确认的审查条件记在 GitHub 总控台和对应任务中。
4. 接入涉及账号、权限、付费或对外写入时，先按大改动清单取得该项目批准；凭证不进入仓库。调用失败不得描述成审查通过。

接入状态由项目总控台维护：未连接 / 已核实可调用。APO 的项目状态和决定仍以 GitHub 原始记录为准。
